# 排障指南

当遇到连接不稳定、无法组网或节点离线等问题时，可以参考本指南进行系统化排查与修复。

---

## 1. 快速排障四步法

在遇到网络问题时，推荐按以下步骤收集并检查本地状态：

```bash
# 第一步：核对软件版本
p2wlan --version

# 第二步：查看当前实时网络与节点连接状态
p2wlan status

# 第三步：运行本地一键健康诊断（自动检查驱动、路由与配置）
p2wlan doctor

# 第四步：观察实时守护进程日志输出
p2wlan logs -f
```

---

## 2. 常见问题速查与解决方案

### 1. 无法连接或登录 Control 服务器
- **可能原因**：
  - 服务器地址填写错误（如漏写 `https://` 或端口）；
  - 服务端证书过期或自签名证书未被系统信任；
  - 服务器防火墙未开放对应端口。
- **排查建议**：
  - 在终端使用 `curl -I https://control.example.com` 测试连通性；
  - 检查服务端反向代理配置是否开启了 WebSocket 协议升级（Upgrade）。

### 2. 登录成功但无法启动网络（虚拟网卡失败）
- **可能原因**：
  - 缺少底层虚拟网卡驱动或系统权限不足；
  - Windows 系统未安装或损坏了 Wintun 驱动；macOS 未允许系统网络扩展。
- **排查建议**：
  - **Windows**：重新以管理员身份运行客户端安装程序，确保 Wintun 正常加载；
  - **macOS**：在“系统设置 → 隐私与安全性”中确认已允许 P2WLAN 的系统扩展或网络权限；
  - **Linux**：确认内核已加载 TUN 模块（`lsmod | grep tun`），若未加载可执行 `sudo modprobe tun`。

### 3. 设备始终显示走中继（Relay），无法建立 P2P 直连（Direct）
- **原理解释**：
  - P2WLAN 默认采用 Direct-first 策略。打洞期间会先尝试 P2P 直连；若双方处于恶劣网络环境下，为了保障业务不中断，会自动切换至加密 Relay 转发。
- **排查建议**：
  - **NAT 类型限制**：如果两端同时处于双对称型 NAT（Symmetric NAT / 俗称 Hard NAT），打洞难度极高。建议至少有一方开启路由器 **UPnP** 或开启 **IPv6**，P2WLAN 能自动通过 IPv6 建立极速直连；
  - **防火墙限制**：检查本地安全软件或云服务商安全组是否拦截了 UDP 流量；
  - **观察状态变化**：网络环境改善后，P2WLAN 会在后台持续尝试将连接无缝恢复为 Direct 直连。

### 4. 虚拟 IP 可以 ping 通，但无法访问游戏服、Web 或 SSH 业务
- **排查建议**：
  - **监听地址检查**：检查目标服务（如 Minecraft 服务器、Web 服务、SSH）是否监听在 `0.0.0.0` 或分配的 P2WLAN 虚拟 IP 上。如果服务仅监听在 `127.0.0.1`，则外部设备无法连接；
  - **宿主机防火墙**：检查目标机器系统防火墙（Windows Defender 防火墙、Linux iptables/ufw）是否允许该端口的入站连接；
  - **路由状态**：运行 `p2wlan route verify` 确认系统路由表是否正常，必要时运行 `p2wlan route repair` 进行自动修复。

### 5. 提示配置目录权限错误或本地 401
- **可能原因**：
  - 历史操作中曾使用 `sudo` 运行客户端，导致用户目录下的文件属主被修改为 root。
- **排查建议**：
  - 日常运行客户端无需 `sudo`；
  - 桌面客户端会在启动时自动检测并尝试修复所属目录的权限；若仍有异常，可手动将配置目录属主改回当前用户：
    ```bash
    sudo chown -R $USER:$USER ~/.config/p2wlan ~/.local/share/p2wlan
    ```

## 3. 导出诊断支持包（Support Bundle）

如果问题仍未解决，需要向服务管理员或技术支持寻求帮助，可以通过支持包功能一键导出系统运行快照：

```bash
# 生成本地诊断压缩包（不包含任何敏感密码、密钥或业务载荷）
p2wlan support-bundle
```

支持包内会自动汇总当前客户端版本、网络状态快照、NAT 行为评估与脱敏的错误日志，方便技术人员快速定位打洞协商或路由异常。在确认目标与必要性后，可将其发送给管理员协助排查。
