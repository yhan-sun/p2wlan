# 房间指南

在 P2WLAN 中，“房间（Room）”是组织多台设备相互通信的核心单元。它类似于一个加密的虚拟局域网交换机，专为游戏联机、团队协作或特定设备分组而设计。

---

## 1. 房间的核心特性

- **独立私网隔离**：每个房间拥有独立的虚拟 IP 网段与安全边界。即使属于同一账号下的设备，不同房间之间的网络也是互相隔离的，互不干扰；
- **点对点优先互联**：加入同一个房间的成员设备，会自动建立端到端加密通道，优先采用低延迟 P2P 直连；
- **灵活的成员管理**：支持查看成员在线状态、设备标识、分配到的虚拟 IP 以及端到端往返延迟（RTT）。

---

## 2. 常用操作

### 图形客户端
1. 在客户端侧边栏点击“互联 / 房间”；
2. **加入房间**：输入房主提供的房间号或房间 ID，点击加入；
3. **查看详情**：在房间详情页中，可以直观查看所有在线成员、各自的虚拟 IP、当前连接方式（Direct 直连或 Relay 中继）与实时延迟；
4. **离开房间**：在房间菜单中选择“断开”或“退出房间”。

### 命令行（CLI）
```bash
# 列出当前加入或可用的房间
p2wlan room list

# 连接并连入指定房间
p2wlan room connect <房间号或房间 ID>

# 断开指定房间连接
p2wlan room disconnect <房间号或房间 ID>

# 查看当前连接的详细网络状态
p2wlan status --json
```

---

## 3. 多房间支持与平台特性

- **桌面端（Windows / macOS / Linux）**：
  桌面客户端支持同时连接并管理多个房间，每个房间作为独立的网络 Profile 运行，并拥有各自独立的诊断与网络通道；
- **移动端（Android）**：
  受操作系统 VPN 框架的单活动网络限制，移动端在同一时刻仅能维持一个活跃网络连接。

---

## 4. 联机游戏实战提示（如 Minecraft / 幻兽帕鲁）

1. **统一加入房间**：所有参与联机的朋友在客户端中加入同一个房间；
2. **确认对端在线**：在房间列表中确认房主（主机）状态为“在线”，并复制房主的虚拟 IP（如 `10.x.x.x`）；
3. **主机开放服务**：房主启动联机游戏（例如开启局域网开放或启动独立服务端），确保服务端绑定的地址为 `0.0.0.0` 或 P2WLAN 虚拟 IP，且系统防火墙已允许该端口入站；
4. **玩家连接**：其他玩家在游戏中通过房主的虚拟 IP 及端口直接连接，享受如同在同一局域网下的低延迟联机体验。
