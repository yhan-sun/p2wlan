# 房间指南

房间把设备成员、权限和虚拟地址放在独立边界内。控制面成员列表、daemon 加密会话和业务数据面是三个不同状态。

## 常用操作

    p2wlan room list
    p2wlan room connect <房间号或房间 ID>
    p2wlan room disconnect <房间号或房间 ID>
    p2wlan status --json

桌面客户端可在房间详情中查看成员、虚拟 IP、当前路径和延迟。移动端受系统 VPN 与单活动网络限制；桌面端可以管理多个房间，但每个房间仍受独立授权和地址边界约束。

## 权限与地址

房间成员必须同时满足设备身份、房间权限、地址授权和未过期的本地租约。批准、暂停、阻止、移除和重新分配地址会使旧会话失效；地址未变化的保存操作不会制造新的重连。

不要把“已建立加密会话”当作“业务一定互通”。需要同时检查授权状态、最近收发数据、路由和目标应用监听状态。不同房间或个人网络之间不能因为地址显示相似而互访。

## 多房间

多房间运行时使用独立 profile、诊断端口和生命周期。端口冲突、地址重叠、无法确认进程身份或授权过期时，客户端应拒绝启动该实例，不强制杀死无关进程。
