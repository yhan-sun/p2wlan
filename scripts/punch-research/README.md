# NAT 诊断研究工具

本目录只保存可重复运行的诊断与模拟工具，不保存个人环境、真实主机地址、阶段性结论或运行日志。

常用入口：

- `puncher.py`：端到端打洞模拟器与诊断工具。
- `nat_sim.py`：可注入映射、分配、过滤和 hairpin 行为的本地模拟器。
- `run_matrix.py`、`run_matrix_p2.py`：运行本地场景矩阵；输出写入被忽略的 `artifacts/`。
- `run_grid.py`、`summarize.py`：参数探索与本地汇总。
- `live_run.sh`：在用户明确提供测试端点时启动单端真实网络探测。

这些脚本是工程工具，不是产品运行时依赖。真实网络证据应作为外部发布或事件附件保存，并在报告中绑定源码提交、二进制 SHA-256 和运行配置；不要把证据回写到仓库。
