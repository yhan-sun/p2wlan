# RECOMMENDED_PARAMS.md — 推荐参数（S5 网格校准结论）

## 推荐值（puncher 默认参数）

| 参数 | 推荐 | 依据 |
|---|---|---|
| `--predict-n` | 8 | 主场景（apd-linear×apd-linear）N∈{8,12,16} 均 100% 达标；8 探测包/轮代价最小 |
| `--window-w` | 2 | 保留双向窗口预测引擎（S1 核心）；W=0 在模拟中同样达标，但真实网络丢包下窗口预测显著优于纯随机（UU 逆向按此实现） |
| `--random-m` | 32 | random 场景（ei×apd-random）M=32 成功率 80-100% 最优；M=64/128 反而下降（探测预算被随机层占用、收益递减） |
| `--pool` | 1 | 主/辅助场景 pool∈{1,3,6} 无显著差异；1 个散射 socket 代价最小 |
| `--keepalive-s` | 25 | 专项验证：10/20/40 对建立成功率与时间无系统影响（单跑 100%，波动为并行噪声）；25s 与 p2wlan 现有建议一致 |
| `--budget-s` | 2.0 | 默认；exact→window→random→sweep 分层预算（见 budget_split 观测） |
| `--sweep` | off | sweep 步进 8 兜底层；命中率 0 时启用（M=32 下 sweep 预算 1638ms 足以覆盖） |

## 达标线验证（网格数据，5 轮/格取中位数）

- 主场景 apd-linear×apd-linear（324 格）：成功率 96-100%，P50 建立 402-411ms，全部满足达标线（≥95% / P50≤1.5s）。
- 辅助场景 ei×apd-random（9 格）：成功率 40-100%，P50 413-453ms。M=32 子格 80-100%；失败格经单跑复现 100% 成功，判定为并行负载下的相位噪声（lo 环路 500ms 端口变化周期与 retry 400ms 的竞争抖动），非参数性失败。
- keepalive 专项（3 值 × 5 轮）：网格内 40%（并行噪声），单跑复现 100%。keepalive 不影响建立。
- 推荐组合（N=8, W=2, M=32, pool=1）：主场景 100% / P50=402ms，cost=11.0（探测包 66/轮 + 1 socket），达标线安全裕度充足。

## 噪声说明（重要）

网格在 6 并行 worker 下运行，loopback 模拟的 500ms 端口变化周期对 CPU 竞争敏感：
相位漂移会暂时错过打洞窗口 → 单轮失败 → 重试 + 5 轮中位数缓解后仍偶发。
结论性判断均基于单跑复现（无并行时 100%）+ 多轮聚合，避免把噪声当作参数效应。
